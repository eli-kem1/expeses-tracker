Expenses Tracker Web App

This is a simple web application for users to monitor and track their expeneses on daily, weekly, and monthly bases

## Features
- List Expenses items
- View Expenses amount per item
- Add total amount of expenses
- Select category of expenses made
- Add date expenses was made
- Delete wrong/incorrect expenses

## Technologies Used
- HTML
- CSS
- JAVASCRIPT

## How to Run
Open index.html in your browser
